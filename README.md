## ✨ Features

* **Perspective Tunnel Scrolling:** A responsive 3D effect that pulls elements inward as the user scrolls down, simulating a deep-space gravity well.
* **Cosmic Chapters:** Includes 8 immersive sections exploring spatial anomalies in sequential order:
    * **Aether** (The primary gateway)
    * **Nebula** (Interstellar clouds of dust)
    * **Void** (The deep unknown)
    * **Eclipse** (The alignment of shadow)
    * **Quasar** (Galactic spiral unspools on scroll)
    * **Wormhole** (Twisting spiral tunnel with rotating rings)
    * **Pulsar** (Rhythmic 3D flip-card timeline with sweeping beams)
    * **Stardust** (Interactive particle cloud with custom cursor repulsion)
    * **Singularity** (The ultimate cosmic destination)
* **Dynamic Visuals:** Custom ambient animations, high-fidelity celestial color palettes, and cinematic transitions.
